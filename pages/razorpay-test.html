Use this page to test the Razorpay checkout. Use test keys (e.g. rzp_test_...) and create an order first (see below).

How to get an Order ID

  1. Get your Key ID and Secret from Razorpay Dashboard → API Keys (use Test keys).
  2. From the aoo-static-gh folder, run in terminal (PowerShell): 
    $env:RAZORPAY_KEY_ID="rzp_test_xxxx"
$env:RAZORPAY_KEY_SECRET="your_secret_here"
node scripts/create-razorpay-order.js
    Replace rzp_test_xxxx and your_secret_here with your keys. The script prints an Order ID.
  3. Copy the printed Order ID into the form below and enter the same Key ID. Click Open Razorpay checkout.

UPI not showing? Enable it in Razorpay Dashboard → Account & Settings → Payment Configuration. Ensure UPI (Apps / Intent / etc.) is enabled and visible for your account.
