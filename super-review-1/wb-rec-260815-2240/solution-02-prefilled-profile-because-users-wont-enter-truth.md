# Keep a pre-filled profile because users will not enter the truth

Users will not type honest current income; they will inflate or leave fields blank.
A pre-filled example profile lets them test 'if this profile does X, what happens?'
This defends the existing pre-fill on Explore banks, not emptying the form.
Decided: pre-fill is the right optimization for this page.

## Exact solution (or idea that can also be a solution)

They praise the three best optimizations and say the pre-filled form optimization is working. Users will put a profile and ask 'if this profile does like this, will it be like this?'—not enter truthful current income. They will think 'who will look?' and put inflated future income or nothing. The direction is to keep/show a pre-filled profile for exploration, not to strip pre-fill or demand honesty.

## What this is for

Explore banks loan-input pre-fill and user honesty. On-screen: Loan inputs form card with pre-filled Monthly income, Property value, Age, CIBIL.
Issue file(s) name the defect; this file is the direction: issue-01-explore-banks-not-obvious-at-a-glance.md.
