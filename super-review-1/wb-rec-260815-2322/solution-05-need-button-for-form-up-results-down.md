## Exact solution (or idea that can also be a solution)
They need a **clear button** for when the loan form comes back above the results. Quote: “Form goes up, answer goes down. How did it go up? I need a button.” Related ideas in the same stretch (not separate files): put tabs where edit is; **no edit**, let it scroll by itself; Myntra (ASR “Mintra”) — cards not same-to-same, selections in a strict manner; “If you want to go up, you can edit it.” Speakers pushed both “let it go” and “I need a button.”

## What this is for

They did not see how the form appeared. They want an explicit control, like a shopping site’s strict selection, not a surprise scroll.
